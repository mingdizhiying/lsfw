# 岚山飞文

网站：https://lsfw.top/　管理：https://lsfw.top/admin 由 gpt生成

当前部署：文字、打卡、评论、Bangumi 与 R2 照片存储已上线；邮件发送服务尚未配置。

## 首次使用

打开管理页面，从本机 `private/setup-token.txt` 复制初始化密钥，设置至少 12 个字符的管理密码。初始化完成后，使用管理员邮箱 `admin@example.com` 和自己设置的密码登录。邮箱不会对外展示。密钥不可放入 public 目录或发送给他人。

## 日常使用

- 首页文案：后台“首页文字”可修改导航、栏目标题、介绍、按钮文字、身份卡寄语、空白提示与页脚。昵称、简介、站名等仍在“个人介绍”修改；日期、打卡与作品数据自动更新。
- 诗集：后台“诗集管理”先建诗集，再写单首诗；可设置介绍、排序及草稿/发布。只有所属诗集和诗都发布后才对外展示。正文为纯文字，保留换行、空行与缩进。诗集入口为 `/poetry`。

- 写博客：可粘贴石墨文档等软件的富文本，保留标题、加粗、列表等基本排版；也支持导入 DOCX、HTML、TXT。复杂字体、分页及任意外部样式不会完全复刻。导入文字不导入图片。
- 每篇博客可设一个密码。公开列表只显示标题与日期等入口信息；关闭或刷新详情页后要重新输入。密码在服务端校验，正文不会预先发到浏览器。这是访问密码保护，并非端到端加密。
- 短笔记、项目、相册独立管理。未发布内容只有管理员可查看。上传相册后会保存为草稿，请确认后发布。
- 照片自动压缩为最长边 2000 像素的 WebP，保存在私有 R2 存储；请另外保存原始照片。后台支持照片说明与封面选择。
- 照片下方的“删除照片”需确认后执行，会永久删除 R2 文件并清理正文、封面和头像引用，无法恢复。横竖照片均完整展示；相册内点击照片可放大，关闭按钮、背景或 Esc 可返回。每本相册有独立且需要审核的评论区。
- 生活打卡每天每项只能点亮一次，支持补记，不能取消；活动可设为私人。年度页展示十二个月的圆盘。
- 留言及评论审核通过后公开。邮箱选填且不公开；回复显示在网站上。
- 邮件通知需要另行配置发送服务 `RESEND_API_KEY` 与已验证的 `MAIL_FROM`。未配置时，回复邮件保留在待发送队列，可在后台重试；网站回复不受影响。
- Bangumi 自动读取账号 的公开资料、收藏与时间轴，缓存 15 分钟；上游故障时展示上次成功数据和更新时间。

## 部署与维护

Node.js 22+。`npm ci` 安装依赖；`npm run check`、`npm test` 检查；`npm run dev` 本地启动；`npm run deploy` 发布到已有 feiwen Worker。D1 数据库为 lsfw-content，预定 R2 桶名为 lsfw-media。域名绑定沿用 Cloudflare 控制台里的 lsfw.top。

账户持有人开通 R2 后，创建 lsfw-media 桶，在 wrangler.jsonc 加入 `"r2_buckets": [{"binding":"MEDIA","bucket_name":"lsfw-media"}]`，重新部署即可接通上传。保持桶私有，不启用公共开发域名；网站负责检查每张照片的访问权限。

数据库迁移：`npx wrangler d1 migrations apply lsfw-content --remote`。不要把 `.wrangler` 的本地测试数据库上传到线上。`.dev.vars` 仅供本地开发。

后台“账户与备份”导出内容、评论与打卡 JSON；照片二进制不包含在内，需另外备份 R2。备份可能包含非公开内容及访客邮箱，应私下保存。数据库还可使用 `npx wrangler d1 export lsfw-content --remote --output private/database.sql` 导出。

`node setup-secret.mjs` 创建或复用本机初始化密钥并写入 Worker secret；不会打印密钥。正式管理员初始化后此入口自动关闭。忘记管理密码时需通过 Cloudflare 管理权限执行受控恢复，不向公开访客提供密码重置接口。

诗集页支持按诗集、全部单诗切换，并在网址中保留视图。单诗列表仅显示已发布诗集中的已发布作品。

诗集支持上传封面、编辑日期；单首诗仍可编辑写作日期。封面在所属诗集发布后公开。
美食页 `/food` 按省份、城市筛选，后台“美食记录”可编辑名称、地址、日期、0–5 分评分和文字记录；支持草稿及公开状态，内容包含在备份中。
